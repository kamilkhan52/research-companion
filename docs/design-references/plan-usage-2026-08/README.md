# Scholiast plan and usage exports

Generated by `scripts/generate-plan-usage-assets.mjs` and rasterized for review by `scripts/render-plan-usage-assets.py`. Each SVG/PNG pair is a 393 × 852 Android frame.

- `00-settings-entry`: enforced Settings entry point
- `01-normal`: comfortable month-to-date spend, with held work treated separately
- `02-approaching`: server warning at or above 80% spend
- `03-exhausted`: persistent monthly refusal shown mid-flow
- `04-busy-not-exhausted`: transient hold collision shown mid-flow
- `05-too-large`: one action larger than the whole Free allowance
- `06-not-enforced`: Settings with every allowance surface omitted
- `contact-sheet-light/dark.png`: final screenshot review sheets

Light and dark exports use the production tokens in `mobile/src/theme/tokens.ts`. All visible text uses the packaged Manrope and Newsreader fonts.
